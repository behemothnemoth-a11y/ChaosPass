# DROP 0005 — Minecraft World Adapter

DROP 0005 adds Minecraft worlds as a real Chaos Pass target instead of treating them as generic folders.

## Added

- `minecraft-world` target detection;
- dependency-free NBT parser for structural world inspection;
- `level.dat` / `level.dat_old` metadata and recovery checks;
- player NBT validation;
- Anvil region header / allocation / overlap validation;
- explicit zero-byte `.mca` placeholder handling;
- datapack ZIP integrity and pack metadata checks;
- enabled datapack existence checks;
- exact duplicate enabled datapack detection;
- function-path collision analysis;
- datapack namespace/function-count inventory;
- unsafe ZIP-member path checks;
- SQLite quick-check validation;
- loose JSON validation;
- static performance/load signals;
- Minecraft-specific Wrong-Way / Charlie / State / Persistence / Regression behavior;
- Minecraft-specific external-driver plans for live UI, accessibility, load/save/reload, performance, soak, and Final Boss testing;
- compact persisted Minecraft audit evidence;
- synthetic Minecraft adapter fixtures/tests.

## Acceptance

The adapter was run against the real `NoteRail Testing` world using a disposable clone.

The original world passed integrity verification.

The adapter correctly distinguished 479 zero-byte region placeholders from actual corruption, validated all 323 non-empty region files and 66,593 chunk records, validated all 15 datapack ZIPs, found the enabled byte-identical Hypa Hypa copy, and reported the 91,865-function enabled load as a static performance signal rather than claiming runtime lag.

## Deliberate boundary

DROP 0005 does not auto-launch Minecraft. Live game behavior remains a structured external-driver task until a stronger isolated Minecraft profile/launcher driver is implemented.
