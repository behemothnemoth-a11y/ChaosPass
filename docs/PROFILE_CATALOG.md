# Profile Catalog

- **Expert Baseline** — normal domain expertise, QA, UX, accessibility, performance/reliability, and security/safety where applicable.
- **Power User** — heavy but legitimate, efficient, advanced use.
- **Boundary Hunter** — minimums, maximums, empties, extremes, naming and path edges.
- **Wrong-Way User** — incorrect order, misunderstood workflow, plausible misuse.
- **Chaos Goblin** — duplication, repetition, stacking, accumulation, absurd quantity.
- **UI Gremlin** — resizing, navigation loops, focus, hidden states, repeated interaction.
- **Performance Murderer** — load, scale, repeated work, resource pressure.
- **Persistence Demon** — save/reload/reopen/interruption/migration and stale-state behavior.
- **State Breaker** — attempts combinations designers assumed were impossible.
- **Charlie** — improvised workflows, bizarre interpretations, wrong-tool solutions, circular fixes, organization chaos.
- **Random Chaos** — a reproducible seed chooses a fixed unpredictable sequence.
- **Wildcard** — observes earlier outcomes and changes strategy mid-run to pursue promising weak spots.
- **Soak Monster** — sustained repeated use intended to expose accumulation and long-session failure.
- **Regression Archaeologist** — replays known historical failures against the current build.
- **Full Chaos Pass / Final Boss** — combines discovered weak points and overlapping stressors.

Charlie and Wildcard are testing philosophies. They are not character impersonations.
