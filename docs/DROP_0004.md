# DROP 0004 — Self-Hardening

DROP 0004 feeds ChaosPass-on-ChaosPass findings back into the framework.

## Findings consumed

The deeper self-pass after DROP 0003 produced strong overall results but revealed two quality issues:

1. subcommand-specific help lacked its descriptive text;
2. configured CLI expectation mismatches were always classified as high-severity BREAK, even for UX-style expectations.

Earlier self-runs had also exposed path-length harness crashes, repeat-workdir collisions, and a Git/autocrlf false positive.

## Changes

- every CLI subcommand now carries a useful description on its own `--help` page;
- configured CLI probes now use context-sensitive default failure classification;
- UX/accessibility/performance expectation misses default to BEND / medium;
- functional QA/state/persistence/regression misses remain BREAK / high by default;
- probe authors can override `failure_status` and `failure_severity`;
- added a first-class regression corpus loader;
- added a regression-corpus adapter for Regression Archaeologist;
- added `list-regressions --target`;
- seeded `regressions/chaospass-selftest.json` with five historical self-findings;
- added regression tests for CLI help and failure classification.

## Validation

Local automated suite after the changes:

- 29 tests passed;
- 1 Windows symlink test skipped because the development account lacks symlink-creation privilege;
- Windows junction escape coverage passed.

The exact deeper ChaosPass-on-ChaosPass configuration that had previously produced a false UX BREAK was replayed after the fixes:

- CATASTROPHIC: 0
- BREAK: 0
- BEND: 1 — expected Windows path-length boundary characterization
- WEIRD: 0
- BLOCKED: 2 — UI Gremlin and accessibility still require a richer external driver
- SURVIVED: 55
- original integrity: PASS

Regression Archaeologist detected and surfaced all five historical `CP-SELF-00x` cases during the replay.

## Goal

Running Chaos Pass on Chaos Pass should improve Chaos Pass rather than merely generate a report. Historical self-findings should become durable regression material.
