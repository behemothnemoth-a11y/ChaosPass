# DROP 0001 — Foundation

First major Chaos Pass drop.

## Included

- zero-trace baseline / clone / verify lifecycle;
- full Markdown + JSON reports;
- explicit result vocabulary: SURVIVED, BEND, WEIRD, BREAK, CATASTROPHIC, BLOCKED;
- expert-first full-pass orchestration;
- generic filesystem-safe stress probes;
- Charlie profile;
- separate Random Chaos and adaptive Wildcard profiles;
- generic Final Boss combination probe;
- CLI runner;
- regression-friendly deterministic seeds;
- architecture and safety contracts;
- unit and smoke tests.

## Intentionally not faked

UI, persistence, state-machine, regression-history, domain-expert, security, and application-specific probes require adapters. Until an adapter exists, those checks appear as BLOCKED in reports instead of silently poking live state.

## Next drop direction

Adapter SDK + first concrete adapters, richer evidence capture, historical regression corpus, performance sampling, and profile learning from prior reports.
